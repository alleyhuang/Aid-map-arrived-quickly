# Aid-map-arrived-quickly

## 项目简介
这是一个微信小程序项目，旨在快速提供援助信息地图服务。

## 功能特性
- 查看附近的援助请求
- 发布援助需求
- 联系援助提供者

## 安装与运行
1. 克隆项目到本地：
   ```bash
   git clone <项目地址>
   ```
2. 使用微信开发者工具打开项目。
3. 配置云开发环境（如果需要）。
4. 点击编译运行。

## 使用说明
1. 打开小程序后，首页会显示附近的援助请求。
2. 点击列表项可以查看详情。
3. 在发布页面填写援助需求信息并提交。

## 项目结构
- `pages/`: 存放小程序页面
- `components/`: 存放公共组件
- `cloudfunctions/`: 存放云函数
